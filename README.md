# 🌐 iCoder Website

A simple static website built using **HTML, CSS, and Bootstrap**, created to practice basic frontend development and responsive design concepts.

🔗 **Live Demo:**  
https://haniaarshad890.github.io/iCoderWebsite/

---

## 📁 Project Structure

iCoderWebsite/
- index.html – Home page  
- about.html – About page  
- contact.html – Contact page  
- style.css – Custom styling  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Bootstrap  

---

## ✨ Features

- Responsive design using Bootstrap  
- Multiple pages (Home, About, Contact)  
- Clean and simple UI  
- Beginner-friendly frontend project  

---

## 🚀 Deployment

The website is deployed using **GitHub Pages**.

---

## 📌 Purpose

This project was developed for learning and practice to strengthen fundamentals of frontend web development.
